# Image generation prompt

The reusable launch background was created with the built-in image-generation
workflow using this production prompt:

```text
Use case: ads-marketing
Asset type: reusable launch background and social-preview backdrop for an
open-source developer analytics tool
Primary request: Create a premium abstract editorial technology background
representing a private local analytics ledger for ChatGPT Codex work—thread
timelines, token streams, runtime pulses, model comparison and cost signals—
without showing a literal application interface.
Scene/backdrop: deep near-black olive-black field with subtle layered data-grid
depth, faint ledger columns, small connected signal nodes, delicate flowing token
trails, and restrained soft glows.
Style/medium: sophisticated 3D-meets-vector generative data art, clean modern
developer-tool branding, highly polished, understated, not cyberpunk.
Composition/framing: wide 16:9 composition; keep the left-center area calmer and
darker for later logo/copy overlay; place most visual energy toward the right
third; strong depth but no identifiable hardware.
Lighting/mood: quiet, private, precise, trustworthy; soft luminous accents.
Color palette: #10120e near-black, #f1ecdf warm ivory, #d7ff5f acid lime,
small restrained #88bfff blue and #ff8067 coral accents.
Constraints: no text, no letters, no numbers, no logos, no OpenAI knot, no
ChatGPT logo, no Codex wordmark, no screenshots, no browser frame, no watermark.
Avoid: generic neon cyberpunk, purple gradients, busy clutter, crypto aesthetics,
floating coins, robot heads, padlocks, stock-photo feel.
```

All typography, logos, UI panels, metrics, disclaimers, and export dimensions were
then composed deterministically from the repository’s existing visual system.
